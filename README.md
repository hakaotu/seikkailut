# Seikkailut

Selaimessa toimiva oppimispeli 1.–2.-luokkalaisille: matikka, suomen sanat
ja espanja yhdessä sovelluksessa. Toimii tietokoneella ja iPadilla.

- Sovellus: `app/` (tavallisia staattisia tiedostoja, ei käännösvaihetta)
- Paikallisesti: `npm run serve` ja avaa http://127.0.0.1:8080/
- Testit: `npm install`, `npm run test:unit`, `npx playwright test`
- Suunnitelmat ja tehtävät: `docs/`
